# 문제 정의

상태: 팀 합의 전. 아래 항목을 확정한 PR부터 분석을 시작합니다.

| 항목 | 팀에서 정할 내용 |
| --- | --- |
| 대상 설비와 주제 | 무엇을 분석하는가 |
| 현장 문제 | 어떤 점검·보전 판단을 돕는가 |
| 분석 단위 | 한 표본은 코일·버스트·세션 중 무엇인가 |
| 정상·이상 정의 | 기준과 근거, 라벨 유무 |
| 성공 기준 | 정답 라벨 유무에 맞는 정량·정성 기준 |
| 범위와 제외 항목 | 이번 프로젝트에서 판단하지 않는 것 |
| 결과 활용 | 누가, 언제, 어떤 조치를 판단하는가 |

고장시각이나 RUL 정답이 없는 데이터라면 고장 예측 성능으로 표현하지 않습니다. 검토용 이상 후보와 검증된 고장 라벨을 구분합니다.
