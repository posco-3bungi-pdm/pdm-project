## 온도 대조 그림을 읽는 법

- 06~07 폴더의 세로선: 감지=갈색, 착수=보라, 완료=녹색. 위 정비 막대에는 동시에 진행된 다른 WO도 표시한다.
- 회색=온도 미관측, 옅은 황색=대기, 옅은 보라=작업. 회색 구간을 잇거나 보간하지 않는다. 점선 CR1 이벤트는 최근 강종 기록과 연결해 읽는다.
- 전체 그림은 실제 시간축의 1분 중앙값이다. 확대는 실제 1~수초 측정값, 같은 존 OP(없는 경우 보조 OP임을 명시), 1분 내 IQR, TC 11개 참조 이탈 점수다.
- 참조는 감지 이전 동일 LOT·강종의 관측값이며 정상 확정 구간이 아니다. 점수 4 초과 3분 지속은 탐색용 변화 후보다. 원인·경보·고장 라벨로 쓰지 않는다.
- 44건 중 전후 24시간 창에 온도 관측이 있는 WO는 10건이다. 충분한 감지 전 참조와 완료 후 동일 조건의 관측이 함께 있는 사례가 없어 회복시간은 NA로 남는다.
- 기록 대기시간과 실제 관측시간은 다르며 가동 여부는 알 수 없다. 수치표는 노트북 실행 결과로만 확인하며 별도 데이터 파일을 생성하지 않는다.

## 색과 기호

- BM 적갈색 = 사후정비, CBM 황갈색 = 상태기반정비, TBM 청회색 = 시간기준정비. 정상·고장 심각도를 나타내는 색이 아니다.
- ◆ 감지, 점선 감지~착수 대기, 막대 착수~완료 작업, ● 착수, ■ 완료.
- 통합 그림의 //는 대기가 6시간을 넘는 부분의 축 생략. 실제 대기시간은 별도 분 열에 생략 없이 표시한다. 작업 막대는 모든 행에 동일한 시간 배율을 쓴다.
- 보라색 글자 = 실제 부품교체 기록. 녹색 글자 = 작업 중 실제 온도 측정 행 존재. 작업 상세의 진회색 막대 = 정지시간 DOWN_MIN.
- 옅은 청회색 행 = CR1 정기수리 캘린더와 작업 구간 겹침. 작업 상세의 옅은 노랑 = 두 WO 작업 구간의 실제 교집합.

## 데이터 해석

- 대기시간=STRT_DT−DETC_DT, 작업시간=END_DT−STRT_DT. 원문 시각과 REMARK·FAIL_MODE 빈 값을 보존한다.
- DOWN_MIN은 정지시간 길이다. 정지 시작·종료 시각과 부품교체 시각은 만들지 않는다.
- 온도 기록은 실제 MEAS_DT 행을 검사한다. 작업 중=[STRT_DT, END_DT), 감지=DETC_DT 정확 일치. 측정값의 정상·이상을 판단하지 않는다.
- 가까운 LOT는 감지 시각과 각 LOT 시작·종료의 거리가 72시간 이내인 경우다. LOT 사이를 채우거나 실제 소재·정비 효과로 연결하지 않는다.
- 정기수리는 CR1 캘린더의 원본 날짜 범위이며 종료일을 포함한다. 실제 정지 구간의 증거가 아니다.
