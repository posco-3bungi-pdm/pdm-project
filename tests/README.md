# 검사

저장소 루트에서 실행함.

```bash
python -m unittest discover -s tests -v
```

- Markdown 그림과 문서 링크가 실제 파일을 가리키는지 확인함
- 결과보고서에 취소선으로 보일 물결표나 그림 폭 표기가 남았는지 확인함
- 보고서 표와 이미지 경로가 HTML로 제대로 바뀌는지 확인함
- 혼동행렬의 합, Precision, Recall, F1 계산을 확인함

작은 예시 데이터와 저장소 문서를 사용함.
원본 CSV는 필요 없고 모델도 학습하지 않음.
모델 성능을 검증하는 시험과는 구분함.
