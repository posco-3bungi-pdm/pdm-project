# 데이터 계약과 검증

상태: 대상 데이터 확정 후 작성.

| 확인 항목 | 기록할 내용 |
| --- | --- |
| 독립 표본 | 행과 실제 분석 단위의 관계 |
| 시간 | 시각 컬럼·타임존·수집 간격·관측 공백 |
| 그룹 | 설비·코일·버스트·세션 식별자 |
| 품질 | 결측·중복·상수·이상값 처리와 근거 |
| 조인 | 연결 키·관계·매칭 실패 건수 |
| 분할 | 시간 경계·그룹 분리·누수 방지 |
| 전처리 | 학습 구간 fit, 과거 정보만 사용하는 처리 |
| 특징 | 정의·단위·계산 창·필요한 과거 길이 |
| 테스트 | 위 조건을 코드로 확인하는 검증 항목 |

정비이력은 운전 측정 데이터와 별도로 관리하고 필요한 시점·이벤트만 대조합니다. 향후 결과를 알려주는 정비 코드나 알람을 입력 특성으로 무심코 사용하지 않습니다.
