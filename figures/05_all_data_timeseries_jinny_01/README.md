연간 그림에는 같은 경로의 SVG도 있습니다. 저장 해상도 160 dpi에서 글자 겹침·잘림·범례 위치 검사를 통과했습니다.

수리 전후 그림은 강종변경 전→후 값, 관측 범위, 개별 CAL01 WO와 REMARK를 나누어 보여줍니다. 온도는 전체 관측 다음에 가열 TC·OP 원본을 확대했습니다.

DETC_DT는 정비이력의 감지 기록 시각입니다. 감지 방법·수치·기준이 없으므로 센서 고장 알람으로 확정하지 않습니다. 부품교체 마커는 실제 교체 시각이 없는 기록을 WO 완료 시각에 연결한 것입니다.

11월 31 COIL = TBM·CBM 양쪽 8 + CBM만 13 + 작업 없음 10입니다. 작업과 겹친 21에는 양쪽 8이 포함됩니다. 시간 교집합은 같은 소재나 고장 원인을 증명하지 않습니다.

통계 비교는 02, 가설 검증은 03, 모델링 준비는 04에 연결합니다.
