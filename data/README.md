# 데이터 준비

원본 데이터는 공개 GitHub 저장소에 올리지 않습니다. 팀이 공유받은 배포 자료를 각자의 `data/raw/`에 두고 분석합니다. Git은 이 안내문만 추적합니다.

주제가 확정되면 아래 항목을 작성합니다.

| 항목 | 기록할 내용 |
| --- | --- |
| 출처와 이용 조건 | 제공자, 공식 배포 경로, 재배포 가능 여부 |
| 확보 방법 | 팀원이 같은 자료를 준비할 수 있는 단계 |
| 파일·버전 | 파일명, 제공일, SHA-256 등 동일성 확인 방법 |
| 읽기 설정 | 인코딩, 구분자, 시각 형식, 단위 |
| 분석 단위 | 코일·버스트·세션 등 독립 표본 정의 |

P제철 배포본을 사용하면 교육용 재현 데이터임을 명시합니다. 데이터 사전의 특징 정의를 확인한 후 사용합니다. 실제 프로젝트의 재현 명령은 README에 추가합니다.
