결과보고서는 모델 실험과 오류 사례를 정리한 문서임.
시계열 분석 보고서는 정수진이 작성한 54쪽 원본임.

`assets/`에는 표지 그림과 로고를 둠.
분석 그래프는 기존 `figures/` 경로를 그대로 사용함.

보고서 생성 코드는 [src/build_report.py](../src/build_report.py)에 있음.
생성 중간 파일은 `build/reports/`에 저장하고 Git에는 올리지 않음.
